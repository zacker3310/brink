# brink

**WORLD WAR**, a modern geopolitical strategy game built on simultaneous turns. Every nation plans in
secret; when orders lock, the world moves at once.

```sh
pnpm install
pnpm dev          # http://localhost:5173
pnpm check        # typecheck, lint, unit tests
pnpm test:soak    # 100 AI-vs-AI matches
pnpm test:e2e     # browser journey
```

See `docs/architecture.md` for the design, `PROGRESS.md` for status, `AGENTS.md` for conventions.
