# Intent: WORLD WAR first playable milestone

**id:** T1   **originator:** Zac, 2026-10-25   **repo:** brink (name kept; game title is WORLD WAR)

## The ask (originator's words, condensed)

"Design and implement the first playable version of a modern geopolitical strategy game"
inspired by Civilization V (hex maps, turns, terrain, readable UI) and Supremacy: World War 3
(modern units, economies, territorial control, logistics). Original game, no copied assets,
layouts, code, data or branding.

"The defining innovation is simultaneous strategic turns. Every nation independently issues
orders during a planning phase. Once orders are locked, the simulation resolves all nations'
decisions against a common world state."

"The result must be a functioning game, not a static prototype."

## Who is affected

A single local player, against three AI nations. Multiplayer is a later concern; the design
must not foreclose it (planning deadlines, WebSocket updates, visibility-filtered views).

## Constraints given

- Stack: TypeScript strict, React, Vite, PixiJS, Zustand, Tailwind, (shadcn/ui where
  appropriate), Fastify, (PostgreSQL + Drizzle when needed), Vitest, Playwright, pnpm
  workspaces + Turborepo, Docker Compose optional.
- Simulation runs headless in Node: no React, Pixi, browser or DB dependencies.
- Single-player needs no external services: in-process worker, local persistence.
- Deterministic: seeded RNG, integer/fixed-point math, iteration order never decides combat.
- One fictional four-nation scenario, 150-300 hexes, completable in 20-30 turns.
- One turn = six simulated hours.
- Maintain AGENTS.md and PROGRESS.md; architecture plan in docs/architecture.md.

## Definition of done (originator's 16 points)

Starts locally; new scenario; four nations on a rendered hex map; inspect territory and
formations; valid move/attack orders; three AI nations generate orders; simultaneous
resolution; combat changes formation state; territory changes hands; resources and production
advance; fog of war affects visible info; match can end by victory; save and resume;
deterministic; automated tests pass; playable without modifying source.

## Open

  `main` root. Whether Pages should serve the built game is not stated.
