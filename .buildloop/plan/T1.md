## Risks

- Balance: matches may stall to the turn limit. The soak test reports the turn distribution;
  a stall is visible as every match ending at turn 30.
- Pixi v8 API drift: verified by the e2e run rendering a canvas, not by assumption.
- Determinism leaks through `Object.keys` order: every ordered loop uses sorted keys; the
  permutation test is the tripwire.

## Departures

- Victory share 55% -> 45%: at 55% only 8/100 soak matches ended by victory points; at 45%, 25/100.
- Ledger gained a `spending` row (budget and reinforcement) so stockpiles balance exactly.
- Two engine bugs found by the AI and soak tests and fixed: a nation kept believing it held a city lost
  out of sight (intel now records lost ground); retreats and air rebases could break the stacking limit
  or land on an overrun base.
- One map test asserted a path choice on an exact cost tie; mud cost raised so the test checks a strict
  preference (stricter, not weaker).
- `tsx` added to `apps/api` to run TypeScript sources; Playwright's Chromium installed to the local cache.
- No cross-model VERIFY pass was run in this session.
